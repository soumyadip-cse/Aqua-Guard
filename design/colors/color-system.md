# AquaGuard — Color System Specification

> Version: 1.0.0
> Status: Design Foundation
> Product: AquaGuard
> Scope: Global color system, semantic colors, surfaces, text, borders, states, 3D lighting, data visualization and accessibility

---

# 1. Purpose

This document defines the official color language of AquaGuard.

All future:

- frontend components
- CSS variables
- design tokens
- charts
- 3D scenes
- hydraulic visualization
- alerts
- buttons
- controls
- status indicators
- animations
- backgrounds
- telemetry overlays

must derive their colors from this system.

No individual component should invent unrelated colors.

The purpose is to create a consistent visual identity based on:

```text
Dark Environment
+
Aquatic Cyan
+
Controlled Amber
+
Semantic Status Colors
+
Neutral Engineering Surfaces
