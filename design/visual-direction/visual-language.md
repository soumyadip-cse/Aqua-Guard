# 1. Purpose

This document translates the AquaGuard visual moodboard into a precise visual language.

The goal is to ensure that every future:

- webpage
- 3D scene
- component
- chart
- control
- animation
- alert
- visualization
- background
- interaction

belongs to the same visual system.

The visual language must communicate:

```text
Engineering precision
+
Water / fluidity
+
Spatial depth
+
Modern technology
+
Calm control
+
Reliability
