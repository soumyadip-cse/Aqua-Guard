> Product: AquaGuard
> Scope: Motion language, animation timing, transitions, 3D animation, telemetry updates, hydraulic flow, pump/valve behavior, alerts, notifications, interaction feedback, responsive behavior, reduced motion and performance

---

# 1. Purpose

This document defines the official motion language of AquaGuard.

Motion is responsible for communicating:

- system activity
- physical water movement
- state transitions
- interaction feedback
- spatial relationships
- alerts
- command execution
- loading
- navigation
- contextual changes

Motion is not decoration.

Every meaningful animation should answer at least one question:

```text
What changed?
Where did it change?
Why did it change?
What is happening now?
What happens next?
